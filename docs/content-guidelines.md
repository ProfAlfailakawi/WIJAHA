# دليل الصياغة والمصطلحات ثنائية اللغة (Content & Protocol Glossary)

## 1. النبرة التحريرية
- **العربية:** فصحى عصرية واضحة، رصينة، خالية من المبالغات الإنشائية وعلامات التعجب، تفهم اللهجة الخليجية في الإدخال وتجيب بأناقة مهنية.
- **الإنجليزية:** Diplomatic British/International English مقتضبة ودقيقة.

## 2. المسرد المعتمد للمصطلحات
| المصطلح بالعربية | المقابل بالإنجليزية | ملاحظة الاستخدام |
|---|---|---|
| الأسبقية البروتوكولية | Order of Precedence | يُرفق دائماً بتنبيه مرجعية الجهة المضيفة |
| الضيف الرئيسي | Chief Guest / Guest of Honour | المقعد رقم 2 يمين المضيف أو قبالته حسب الطاولة |
| قاعة التشريفات / الاستراحة | VIP Holding Lounge | محطة استراحة قصيرة قبل الاجتماع الرسمي |
| قاعدة رسمية | Official Rule (`official`) | مستندة لدليل مراسم مؤسسي معتمد |
| عُرف سائد | Customary Practice (`customary`) | تقليد دبلوماسي أو اجتماعي راسخ |
| إرشاد تقديري | Advisory Guidance (`advisory`) | نصيحة تنظيمية عامة تُوسم بشفافية |
| محتوى تجريبي غير معتمد | Unapproved Demo Content (`draft_demo`) | وسم إلزامي لكافة القواعد قبل اعتماد الخبراء |
