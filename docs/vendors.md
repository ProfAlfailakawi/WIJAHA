# سجل المزودين ومعالجي البيانات الفرعيين (Subprocessors & Vendors)

| المزود | الغرض التشغيلي | نوع البيانات المعالجة | الموقع / الضوابط |
|---|---|---|---|
| **Google Cloud SQL (PostgreSQL)** | التخزين العلائقي الدائم للمشاريع والقواعد والفواتير | بيانات الحساب والمشاريع (الاستفسارات مشفرة `AES-256-GCM`) | `europe-west2` |
| **Firebase Authentication** | مصادقة Google OAuth الاختيارية | البريد الإلكتروني، الاسم، المعرّف الفريد `uid` | Google Cloud |
| **Google Gemini API (`@google/genai`)** | التوليد المهيكل عبر الخادم فقط (عند ضبط المفتاح البيئي) | نص المناسبة والقواعد المسترجعة فقط (دون بيانات الفوترة) | استدعاء خادمي حصراً؛ لا يُعرض المفتاح للعميل |
| **Sandbox Billing Adapter** | محاكاة الاشتراك وإصدار الفواتير في بيئة التطوير | معرّف الباقة والمؤسسة والمبلغ بالدينار الكويتي | داخلي ومحصّن ضد التكرار (`webhook_events`) |
