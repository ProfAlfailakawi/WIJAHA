## ما هو موجود
- تطبيق واحد: Express + React 19 (Vite) + PostgreSQL عبر Drizzle، **44 جدولاً**، **27 مساراً** في الواجهة.
- ملفات ترحيل متعقَّبة في `drizzle/` مع امتداد pgvector.
- طبقات مستقلة: المصادقة والصلاحيات، والفوترة (`mock` و`stripe`)، والبريد (`console` و`smtp`)، والذكاء الاصطناعي (`mock` و`gemini`).
- فحص إعدادات صارم عند الإقلاع: الخادم يرفض العمل في الإنتاج بمزودات وهمية أو مفاتيح ناقصة (`src/server/config/env.ts`).

## الذكاء الاصطناعي — بصدق
| الجزء | بدون مفتاح نموذج (`AI_PROVIDER=mock`) | مع مفتاح (`AI_PROVIDER=gemini`) |
|---|---|---|
| فهم السؤال | قواعد كلمات مفتاحية | نموذج لغوي بمخطط Zod، والقواعد احتياط |
| البحث | معجمي + تطبيع عربي | معجمي + دلالي (pgvector) مدموجان بـ RRF |
| التوليد | قوالب من القواعد المسترجعة | نموذج لغوي، كل كتلة تُتحقق بالمخطط |

**لم يُختبر المسار الحي (gemini) في هذه الجولة لعدم توفر مفتاح.** بعد إضافة المفتاح: `npm run kb:reindex` ثم `npm run evals`.

- `npm run evals` بالمزود الوهمي:

| المجموعة | الحالات | دقة النية | الاسترجاع @10 | قواعد مختلقة | مخرجات ممنوعة | مراجعة خبير للحساس |

| dev | 60 | 100% | 94.7% | 0 | 0 | 100% |
| holdout | 20 | 35% | 70% | 0 | 0 | 100% |
| adversarial | 20 | 30% | — | 0 | 0 | 100% |

الفجوة بين dev وholdout تعني أن قواعد الكلمات مضبوطة على أسئلة التطوير، ولا تفهم الصياغات الجديدة.
الحل هو تشغيل النموذج اللغوي، ثم إعادة القياس. **كل الحالات تجريبية** (`demo: true`)، والاعتماد يحتاج 200 حالة يكتبها الخبراء.

## ما لم يُنفذ بعد
- عزل البيانات داخل قاعدة البيانات (RLS): مؤجل بخطة في `docs/decisions/ADR-004-database-row-level-security.md`. العزل الحالي في طبقة التطبيق ومغطى بالاختبارات.
- المحتوى البروتوكولي: كل القواعد `draft_demo`، ولا تظهر في الإنتاج إلا مع `ALLOW_DEMO_RULES=true`.
- بوابة دفع خليجية (Tap أو MyFatoorah): يوجد Stripe فقط حالياً.
- المراجعة القانونية للشروط والخصوصية.
- مشروع Firebase مستقل لوجاهة.

## قبل الإطلاق التجاري
1. مفتاح نموذج لغوي، ثم `npm run kb:reindex` و`npm run evals`.
2. محتوى معتمد من الخبراء، و200 حالة اختبار حقيقية.
3. مفاتيح الدفع والبريد، ومشروع Firebase مستقل.
4. مراجعة قانونية، واختبار اختراق مستقل.
