# المعمارية الهندسية لمنصة وجاهة | WIJAHA Architecture

## 1. النمط المعماري: Modular Monolith
صُممت المنصة وفق نمط **المونوليث المعياري المتكامل** بلغة TypeScript الصارمة (`strict: true`):
- **`src/shared/*`**: العقود المشتركة (`Zod` schemas)، التطبيع اللغوي العربي وتوسيع اللهجة الخليجية، وحساب تباين الألوان وفق WCAG 2.2 AA.
- **`src/db/*`**: مخطط قاعدة البيانات العلائقية (**Cloud SQL PostgreSQL** عبر **Drizzle ORM**) المكوّن من 31 جدولاً تشمل المعرفة، المستخدمين، المؤسسات، المشاريع وإصداراتها، المحاكاة والكفايات، الفوترة والسجل المحاسبي، والتدقيق الأمني.
- **`src/server/*`**: وحدات مستقلة للمصادقة والصلاحيات (`auth`), الاسترجاع الهجين (`knowledge`), خط المعالجة الذكي سداسي المراحل (`ai`), محرك المحاكاة (`simulation`), التصدير الرسمي DOCX/PDF (`export`), والاستحقاقات والفوترة (`billing`).
- **`src/components/*` & `src/pages/*`**: واجهة React 19 مبنية بنظام التصميم الهادئ (Quiet Luxury) ودعم كامل لاتجاهي `RTL/LTR` والمظهرين الفاتح والداكن.

## 2. خط المعالجة الذكي سداسي المراحل (6-Stage AI Pipeline)
1. **تحليل النية والكيانات (`analyzeIntentAndContextPure`)**: استخراج نوع المناسبة (من 16 نية مصنفة)، الدولة، ومستوى الحساسية (`low | medium | high`).
2. **توسيع المرادفات الخليجية والعربية (`expandGulfSynonyms`)**: تحويل التعبيرات اليومية (`بشت`, `دشداشة`, `بكرة`, `شلون`, `معازيم`) إلى مصطلحات مراسمية فصيحة.
3. **الاسترجاع المعرفي الهجين (`retrieveHybridRules`)**: دمج التطابق النصي والبلدي مع التشابه الدلالي للمتجهات (64-d embeddings).
4. **التوليد المهيكل عبر الخادم (`provider.ts` / `@google/genai`)**: يعمل حصراً في الخادم مع مهلة زمنية ومسار احتياطي حتمي منظم يضمن استمرارية الخدمة 100%.
5. **الفحص الحتمي للمصادر (`verifyAndSanitizeResultPure`)**: يحذف أي معرّف قاعدة غير موجود فعلياً في القواعد المسترجعة (`0` قواعد مختلقة)، ويفرض كتلة `expert_review` وتنبيه الحساسية العالية للمناسبات السيادية والوزارية.
6. **البث التدريجي (`Server-Sent Events`)**: إرسال السياق والملخص والكتل تباعاً مع دعم `aria-live="polite"`.

## 3. العزل متعدد المستأجرين والأمن (Defense-in-Depth)
- كل مشروع وفاتورة ودعوة مرتبط بمعرّف المؤسسة `org_id`.
- طبقة تفويض مركزية `can(actor, action, resource)` تمنع أي قراءة أو تعديل عابر للمؤسسات (`403 CROSS_TENANT_DENIED`).
- تشفير نصوص الاستفسارات وإجابات المحاكاة الحرة في قاعدة البيانات (`AES-256-GCM`)، وتجزئة عناوين IP (`SHA-256`)، وحفظ جلسات الدخول في كوكي `HttpOnly; SameSite=Lax`.
