# ADR-001: اعتماد Express + Vite + React 19 + Drizzle ORM كمونوليث معياري موحّد

- **الحالة:** معتمد
- **التاريخ:** 2026

## السياق
ينص القسم 22.2 من مواصفة البناء على إمكانية استبدال عنصر تقني بمبرر هندسي مكتوب شريطة الحفاظ على TypeScript الصارم (`strict: true`)، وعزل النطاقات، والأمن متعدد المستأجرين، وقاعدة PostgreSQL العلائقية.

## القرار
اعتماد خادم `Express` المدمج مع `Vite` وواجهة `React 19` وقاعدة بيانات **Cloud SQL for PostgreSQL** عبر **Drizzle ORM** في مستودع موحّد واضح الفصل (`src/db`, `src/server/*`, `src/shared/*`, `src/pages/*`).

## المبررات الهندسية
1. **التوافق الأصيل مع بيئة Cloud Run & Cloud SQL**: يتكامل مع موصل مقابس Cloud SQL الآمن ومصادقة Firebase دون تعقيد تعدد الخوادم.
2. **بث SSE مباشر عالي الموثوقية**: يتيح `/api/query` بث مراحل التحليل والكتل فوراً دون انقطاع.
3. **مشاركة صارمة للأنواع (`Zod` + TypeScript `strict: true`)**: تشترك الواجهة والخادم واختبارات التقييم الذهبية في نفس مخطط `WijahaResultSchema` حرفياً.
