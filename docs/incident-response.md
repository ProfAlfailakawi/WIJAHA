# خطة الاستجابة للحوادث الأمنية والتشغيلية (Incident Response Plan)

## 1. تصنيف الحوادث
- **حرجة (SEV-1):** اشتباه وصول غير مصرح به لبيانات مؤسسة أخرى، أو تسرب مفاتيح بيئية، أو خطأ بروتوكولي حرج في قاعدة معتمدة (`approved`).
- **متوسطة (SEV-2):** تعطل مزود التوليد اللغوي الخارجي أو ارتفاع زمن الاستجابة فوق الميزانية المحددة.
- **منخفضة (SEV-3):** بلاغ مستخدم عن صياغة قابلة للتحسين في قاعدة تجريبية.

## 2. إجراءات الاحتواء الفوري
1. **إبطال الجلسات (`auth_sessions`):** حذف جلسات الحساب المتأثر فوراً من قاعدة البيانات.
2. **تعليق قاعدة معرفية (`archived`):** من لوحة `/admin` تبويب المراجعة، تحويل القاعدة المتأثرة إلى `archived` لإيقاف استرجاعها فوراً مع تسجيل الإجراء في `audit_logs`.
3. **استمرارية التوليد:** في حال انقطاع نموذج الذكاء الخارجي، ينتقل `executeWijahaPipeline` تلقائياً إلى المولّد الهيكلي الحتمي دون انقطاع الخدمة.
4. **مراجعة السجل الجنائي:** فحص جدول `audit_logs` (المزوّد بـ `actor_uid`، نوع الحدث، وتجزئة `ip_hash`).
