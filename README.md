# وجاهة | WIJAHA — من البحث إلى التجربة (Version 1 · Phases 1–6)

منصة متكاملة في المراسم والإتيكيت والضيافة والتشريفات، تحوّل سؤال المستخدم الطبيعي (بالفصحى أو اللهجة الخليجية أو الإنجليزية) إلى خطة عمل منظمة وقابلة للتنفيذ والتدريب والتصدير، مع جسر هادئ لخبراء المراسم والتدريب الذكي.

> **تنبيه العلامة والمحتوى:** «وجاهة | WIJAHA» اسم مبدئي قيد مراجعة العلامة التجارية. جميع القواعد البروتوكولية والسيناريوهات المضمّنة في النسخة الحالية موسومة صراحة بحالة `draft_demo` («محتوى تجريبي غير معتمد») إلى حين اعتمادها من خبراء المراسم.

---

## التشغيل السريع

```bash
# 1. تثبيت الحزم
npm install

# 2. تعبئة البيانات التأسيسية ومجموعة الاختبارات الذهبية (60 حالة)
npm run db:seed

# 3. تشغيل الخادم التطويري (المنفذ 3000)
npm run dev
```

---

## الأوامر الهندسية وبوابات الجودة

| الأمر | الوصف |
|---|---|
| `npm run dev` | تشغيل المونوليث المعياري (`tsx server.ts`) مع واجهة React 19 على المنفذ `3000` |
| `npm run typecheck` | فحص TypeScript الصارم |
| `npm run db:migrate` | تطبيق ملفات الترحيل (يتطلب امتداد pgvector) |
| `npm run db:seed` | البيانات المرجعية + البيانات التجريبية (يرفض الإنتاج) |
| `npm run kb:reindex` | بناء الفهرس الدلالي للقواعد (يتطلب مفتاح نموذج) |
| `npm run test:integration` | اختبارات الأمن والعزل على قاعدة بيانات حقيقية |
| `npm run build` | بناء حزمة الإنتاج للعميل والخادم |
| `npm test` | تشغيل اختبارات الوحدات والأمن والعزل متعدد المستأجرين (`node:test`) |
| `npm run evals` | ثلاث مجموعات تقييم: dev وholdout وadversarial، تُعرض كل منها منفصلة |
